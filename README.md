# Midterm Project – GitHub + Weather Data Analyzer CLI

## Project Description

This project is a Node.js command-line application that fetches and processes data from two public APIs:

- OpenWeather API
- GitHub API

The application allows users to search for weather data from a city and GitHub profile information from a username, then saves the results into JSON and TXT report files.

## Features

- Fetch real-time weather data
- Fetch GitHub user profile data
- Validate command-line inputs using Joi
- Save processed data into JSON files
- Generate TXT summary reports
- Command-line interface using Commander.js
- Environment variable support with dotenv
- Jest testing with 100% coverage
